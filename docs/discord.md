# Статус в Discord

Overtone показывает в Discord «Слушает …» с названием трека, исполнителем, обложкой, полоской времени
и кнопками «Слушать в Яндекс Музыке» (или «Открыть на SoundCloud») и «Что за Overtone?».
На паузе статус пропадает, как у Spotify.

Discord показывает статус от имени «приложения», которое надо один раз создать на сайте Discord.
Его ID зашивается в мод (`overtone.discordClientId` в `package.json`) — пользователям ничего настраивать
не нужно. Ниже — как создать приложение автору мода. Пользователи при желании могут сделать то же
самое и вставить свой ID в настройках Overtone, если хотят своё название вместо «Overtone».

## 1. Создать приложение

1. Открой **Discord Developer Portal**: https://discord.com/developers/applications
   и войди своим аккаунтом Discord.
2. Нажми **New Application** (справа сверху).
3. Название — **Overtone**. Именно оно будет в статусе: «Слушает **Overtone**».
   Не называй приложение «Яндекс Музыка» или «SoundCloud»: это чужие товарные знаки, Discord может
   заблокировать приложение, а пользователи — решить, что это официальная интеграция.
4. Поставь галочку согласия с условиями (Developer Terms of Service и Developer Policy) и нажми **Create**.

## 2. Значок и описание

На странице **General Information** только что созданного приложения:

1. **App Icon** — загрузи `assets/logo/icon-256.png` из репозитория (подойдёт и любой квадратный PNG
   от 512×512, Discord сам обрежет). Это значок рядом со статусом.
2. **Description** — например: «Мод для Яндекс Музыки: SoundCloud внутри, клипы, темы, эквалайзер».
3. Нажми **Save Changes** внизу.

Загружать картинки в раздел **Rich Presence → Art Assets** не нужно: обложки треков и значок Overtone
мод отдаёт ссылками, Discord подтягивает их сам.

## 3. Скопировать ID

На той же странице **General Information** найди **Application ID** (длинное число из 18–19 цифр)
и нажми **Copy**. Это не секрет — его можно класть в открытый репозиторий. А вот **Public Key**
и всё в разделе **Bot** никому не давай и никуда не вставляй: они моду не нужны.

## 4. Вписать ID в мод

В `package.json`:

```json
"overtone": {
  "repo": "lovlyDev/overtone",
  "discordClientId": "ВСТАВЬ_СЮДА_ID",
  "ymTested": ["5.127.0"]
}
```

Закоммить и выпусти новую версию — у всех пользователей статус заработает после обновления.
Проверить у себя до релиза: вставь ID в настройках Overtone → Discord → «Своё приложение Discord».

## 5. Проверка

1. Запусти Discord (приложение для компьютера, не сайт — с сайтом статус не работает).
2. В Discord: **Настройки пользователя → Конфиденциальность активности** (Activity Privacy) →
   включи **«Отображать текущую активность как статус»** (Share my activity).
3. Включи любой трек в Яндекс Музыке с Overtone. В настройках Overtone → Discord должно быть
   «Discord подключён», а в твоём профиле — «Слушает Overtone».
4. Кнопки под статусом сам ты не видишь — это ограничение Discord. Попроси друга глянуть твой профиль.

## Если не работает

| Что видишь | Что делать |
|---|---|
| «Не задан ID приложения Discord» | Не вписан `discordClientId` — шаг 4. |
| «Discord не запущен» | Открой Discord для компьютера. Мод сам подключится в течение 15 секунд. |
| Подключён, но статуса нет | Шаг 5.2 — включи отображение активности. Ещё проверь, что Discord не запущен от имени администратора, а Яндекс Музыка — от обычного пользователя (или наоборот): тогда они друг друга не видят. |
| Статус обновляется с задержкой | Discord принимает не больше 5 обновлений за 20 секунд — мод сам выдерживает паузу. |
