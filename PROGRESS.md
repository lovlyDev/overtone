- Исходное состояние сохранено коммитом 2baa43e.
- Ответы Fetch.fulfillRequest на этапе Request имеют status=0, пустые заголовки, читаемое тело.
- На этапе Response сохраняется исходный статус сервера (404), несмотря на responseCode=200.
- Обёртка onHeadersReceived не исправляет проблему: журнал видит только OPTIONS, а не искусственный ответ. Гипотеза из исходного ТЗ не подтвердилась.

- Живая проверка: status=200; родной плейлист с обложкой и строками открывается.
- Добавлен маршрут /users/70/playlists/{kind}, который плеер использует при запуске очереди. У каждого поиска собственный kind.
- Трек появляется в плеере; NEXT переключает метаданные. Звук пока не подтверждён: позиция остаётся 0. Локальный файл доступен, Range даёт 206/audio/mp4.

## Проверка после исправления коллекции

- Зависание «Мне нравится» устранено: API /tracks использует multipart/form-data с повторяющимися trackIds. Смешанные порции сохраняют структуру FormData; номера SoundCloud исключаются из запроса на сервер, карточки объединяются локально. Парсер больше не принимает цифры из границ multipart за trackId.
- Подмешивание «Мне нравится» и счётчика перенесено из CDP Response в fetch/IPC. После перезапуска видны три сохранённых SC-трека и родные треки; бесконечные заглушки в проверенной начальной порции исчезли.
- Воспроизведение заработало с codec=aac, quality=nq вместо aac-mp4/запрошенного lossless. Позиция росла, NEXT переключал трек с продолжением звука, перемотка ползунком на 60 секунд дала позицию 61.3.
- Убрано version=SoundCloud, добавлена оранжевая метка SC и подсветка раздела.
- Проверки tools/test-api.js и tools/check.js проходят. Добавлен тест multipart с цифрами в boundary и смешанными ID.
- Остались непроверенными: полный цикл конца очереди, повтор/перемешивание; сердечки после collection/sync; длинная прокрутка (попытка записи не вызвала запросов, поэтому подтверждения нет); полноэкранные настройки и клипы. В консоли есть сообщения самого приложения No dataRenderingStartTime и MobX о detached nodes; причинная связь с модом не установлена.
