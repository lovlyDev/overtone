<h1 align="center">Overtone</h1>

<p align="center">Мод для десктопной Яндекс Музыки: SoundCloud внутри, клипы, темы, эквалайзер и живой фон.<br>
Windows 10 и 11.</p>

---

## Что умеет

- **SoundCloud прямо в приложении.** Поиск, ссылки на треки, плейлисты и профили открываются родными страницами Яндекс Музыки и играют в родном плеере. Сердечко добавляет трек SoundCloud в «Мне нравится».
- **Замена недоступных треков.** Серые треки, которых больше нет в Яндексе, сами находятся на SoundCloud и играют. Только при точном совпадении названия, исполнителя и длительности.
- **Клипы** в полноэкранном плеере: родное видео Яндекса или клип с YouTube. Клик по экрану — убрать.
- **Живой фон** из обложки, который дышит под музыку, когда клипа нет.
- **Эквалайзер** с готовыми настройками и **громкость**: ровная для всех треков или «Очень громко» — выше 100%, без хрипа.
- **Темы**: AMOLED, Стекло с настоящим преломлением, Контраст, Mica, Acrylic.
- **Глобальные клавиши**, таймер сна, пауза при блокировке экрана и отключении наушников.
- **Без рекламы и Яндекс Метрики.** Скробблинг в **Last.fm** со своим ключом.

## Установка

1. Установи Яндекс Музыку с [music.yandex.ru/download](https://music.yandex.ru/download/) и хотя бы раз запусти.
2. Скачай `Overtone-Setup.exe` из [последнего релиза](https://github.com/lovlyDev/overtone/releases/latest).
3. Запусти и нажми Enter. Установщик сам закроет Яндекс Музыку, поставит мод и откроет её снова.

Windows может предупредить «Неизвестный издатель»: установщик не подписан сертификатом. Нажми «Подробнее» → «Выполнить в любом случае». Контрольная сумма SHA-256 указана в описании релиза.

Настройки — кнопка **Overtone** под логотипом слева или `Ctrl+Shift+O`. Версия мода и «Что нового» — плашка рядом с версией приложения.

## Обновления

- **Мод** проверяет новые версии сам. Обновить — в настройках или в окне «Что нового в моде?», одной кнопкой.
- **Яндекс Музыка** при обновлении стирает мод. Overtone ставит себя обратно автоматически: сразу после обновления и при входе в Windows.
- Если после обновления Яндекс Музыки что-то перестало работать, мод скажет об этом сам и предложит обновиться, а если исправления ещё нет — подождать: разработчики скоро всё починят.

## Удаление

«Параметры» → «Приложения» → «Установленные приложения» → **Overtone для Яндекс Музыки** → «Удалить». Яндекс Музыка вернётся к исходному виду.

## Что установщик меняет в системе

- В папку Яндекс Музыки: небольшой загрузчик в `resources\app.asar`, оригинал сохраняется рядом как `app.asar.overtone-bak`.
- `%APPDATA%\Overtone` — код мода, настройки, кеш клипов и треков, `yt-dlp.exe`.
- Автозагрузка: запись `Overtone` в `HKCU\...\Run` — проверка мода при входе в Windows.
- Запись в «Установленных приложениях».

Всё это убирается при удалении.

## Если что-то сломалось

- **Яндекс Музыка не запускается** — удали Overtone через «Установленные приложения» или переустанови Яндекс Музыку с сайта поверх.
- **Клипы с YouTube не грузятся** — в настройках укажи прокси (YouTube в России работает медленно или не работает).
- Журнал установщика: `%APPDATA%\Overtone\installer.log`. С ним и описанием проблемы — в [Issues](https://github.com/lovlyDev/overtone/issues).

## Для разработчиков

```bash
npm run install-dev   # мод грузится прямо из папки проекта
npm test              # проверки без запуска приложения
npm run build         # dist/Overtone-Setup.exe
```

Релиз: поднять версию в `package.json`, дописать раздел в `CHANGELOG.md`, поставить тег `vX.Y.Z` и запушить — GitHub Actions соберёт установщик и выпустит релиз. В `package.json` → `overtone.ymTested` — версии Яндекс Музыки, с которыми релиз проверен: по ним мод решает, предлагать ли обновление после поломки.
